| Arquivo/pasta      | Função                                                                              |
| ------------------ | ----------------------------------------------------------------------------------- |
| `assets/`          | Arquivos **estáticos** do projeto, como CSS, JS e imagens.                          |
| `img/`             | Imagens usadas pelo projeto.                                                        |
| `listaEspera/`     | **Aplicação Django** que contém a lógica do sistema.                                |
| `setup/`           | Configurações principais do projeto Django, como `settings.py` e `urls.py`.         |
| `static/`          | Arquivos estáticos (CSS, JS, imagens) usados nas páginas.                           |
| `status_api/`      | Aplicação responsável pela **API de status** do sistema.                            |
| `templates/`       | Contém os arquivos **HTML (Templates)** exibidos ao usuário.                        |
| `.env.example`     | Modelo das variáveis de ambiente necessárias, como senhas e configurações.          |
| `.gitignore`       | Define arquivos/pastas que o **Git não deve versionar**.                            |
| `Dockerfile`       | Instruções para criar a **imagem Docker** da aplicação.                             |
| `README.md`        | Documentação do projeto e instruções de uso.                                        |
| `compose.yaml`     | Configura os **serviços Docker** usados pelo projeto.                               |
| `entrypoint.sh`    | Script executado ao iniciar o container, preparando/iniciando a aplicação.          |
| `manage.py`        | Ferramenta de comando do Django para executar tarefas como servidor, migrações etc. |
| `requirements.txt` | Lista as bibliotecas Python necessárias para o projeto.                             |
