Operação orientada

O que você precisa fazer?

Escolha um fluxo pelo objetivo. A sequência abaixo indica o caminho recomendado para configurar e operar cada ambiente.

01

Primeira configuração

Preparar um ambiente institucional

Use este fluxo ao cadastrar uma nova organização, como o CAMPPG, e publicar seu primeiro endereço.

  1. Crie a organização e defina a situação do ambiente.
  2. Na própria organização, adicione identidade visual e domínio.
  3. Depois, afilie ou convide as primeiras pessoas.
Criar organização Ver organizações
02

Acesso e pessoas

Controlar quem entra

Use este fluxo para dar acesso ao tenant sem abrir o ambiente para visitantes não afiliados.

  1. Use Afiliações para vínculos já confirmados.
  2. Use Convites para entradas pendentes.
  3. Revise papel e situação antes de liberar o acesso.
Afiliações Convites
03

Acompanhamento

Operar projetos

Use este fluxo para acompanhar o conteúdo sem confundir projetos autorais com projetos institucionais.

  1. Filtre projetos por organização, status e visibilidade.
  2. Consulte links, membros e marcos quando necessário.
  3. Use comentários e solicitações apenas para suporte operacional.
Ver projetos Ver marcos
04

Manutenção

Revisar e corrigir

Use este fluxo quando houver uma inconsistência, troca de responsável ou necessidade de auditoria.

  1. Confira o status da organização e do domínio.
  2. Revise afiliações, convites e permissões.
  3. Consulte o histórico do objeto antes de alterar dados.
Revisar domínios Ver usuários
Regra de segurança: configure a organização antes das afiliações e nunca use o domínio global para validar conteúdo institucional.
